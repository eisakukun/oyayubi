# おやゆび / OYAYUBI

声から、モザイクから、顔へ。

知らない誰かとつながるビデオ通話。いきなり顔は出ません。

1. **声だけ** — 顔は相手に送られていません
2. ふたりで**親指を7秒**合わせられたら、顔が**モザイク**で出ます
3. そこから**5分**話すあいだに、モザイクは少しずつほどけていきます
4. 最後にもう一度**7秒**。そこで、ぜんぶ。

**指が合ったあとに離したら、その場で通話は終わります。** 同じ相手には戻れません。
「見せていい？」を、言葉ではなく指で確かめる。逃げ道のない7秒。

## 作りで大事にしたこと

顔は「ぼかして表示」しているのではありません。**送る前にモザイクをかけています。**
自分の端末で、見せると決めた粗さの絵だけを canvas に描き、それを相手に渡します。
まだ見せていない細かさの絵は、相手の端末に存在しません。

## 使い方

- **ひとりで体験する** — 仮の相手（日本語音声つき）と最後まで通せます
- **いま誰かとつながる** — 待っている人がいればつながり、いなければ待つ側になります
- **あいことばで会う** — 片方が空のまま「入る」を押すと4けたが出ます。もう片方がそれを入れます

入口で「本番の長さ（7秒→5分→3分）」と「実演の長さ（7秒→30秒→18秒）」を選べます。

通信は PeerJS（P2P）。映像も音声も、あいだのサーバーには残りません。
